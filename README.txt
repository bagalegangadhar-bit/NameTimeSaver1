# Name & Time Saver (Android source project)

Features:
- Save name, date, and time
- Data persists on the phone using Android SharedPreferences
- Search entries
- Edit and delete saved entries

## Build an APK
1. Install Android Studio on a computer.
2. Open this `NameTimeSaver` project folder in Android Studio.
3. Let Gradle sync finish (internet may be needed the first time).
4. Select **Build > Build APK(s)**.
5. Android Studio will show the APK location, usually `app/build/outputs/apk/debug/app-debug.apk`.
6. Transfer the APK to your Android phone and install it. You may need to allow installation from that source.

This chat environment did not compile or sign an APK. This ZIP contains the Android Studio source project, not a ready-to-install APK.
